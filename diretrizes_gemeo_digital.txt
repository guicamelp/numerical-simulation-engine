1. ARQUITETURA MULTIFÍSICA (Acoplamento Sequencial)
- Intuição: O sistema opera em cadeia determinística.
- Fluxo Algébrico: 
  1. Balanço Térmico: Resolve-se a placa sólida.
  2. Modulação Hidráulica: Atualiza-se a viscosidade $\mu(T)$ via relação empírica:
     $\mu(T)=\frac{0.001791}{1+0.03368~T+0.000221~T^{2}}$.
  3. Acoplamento Monolítico: Resolve-se a dinâmica da membrana com a rede hidráulica.

2. MODELAGEM ESTOCÁSTICA (Amostragem de Monte Carlo)
- Intuição: Sistemas com incerteza física (obstrução de canais) sofrem explosão combinatória ($2^{n_c}$ estados), tornando a busca exata inviável. O método de Monte Carlo aproxima a probabilidade do evento crítico através de $N$ amostras aleatórias.
- Formulação da Obstrução: Se um canal falha (probabilidade $p_o$), sua condutância cai: $C_{k} \leftarrow C_{k}/f_{obs}$.
- Indicador Estacionário: Limite de vazão $\mathfrak{q}_{inlet} = A[0,:] \cdot p < 1.25\times10^{-5}$.
- Indicador Dinâmico (Energia Dissipada): A potência instantânea é $p^{T}(t)\mathbb{A}p(t)$. O funcional de energia exige integração no tempo (limite crítico $\mathscr{P} < 7.0$):
  $$\mathscr{P}=\int_{t_{i}}^{t_{f}}p^{T}(t)\mathbb{A}p(t)dt$$
- Erro Assintótico: O erro do estimador decai com $N^{-1/2}$.

3. APRENDIZADO DE MODELOS (Aproximação e Regressão)
- Intuição: Mapear o comportamento dinâmico $\mathscr{P}(t)$ a partir de amostras discretas para realizar previsões ou filtrar ruídos.
- Interpolação Linear/Cúbica: Polinômios locais que garantem $v(x_i) = y_i$ sem oscilações de borda (Fenômeno de Runge) típicas de polinômios globais de alto grau.
- Regressão (Mínimos Quadrados): Para sistemas sobredeterminados ($n > m$), minimiza-se a norma Euclidiana quadrática do resíduo $||r||_{2}^{2}$. 
  Resolve-se via Equações Normais (matriz simétrica definida positiva):
  $$\mathbb{A}^{T}\mathbb{A}c=\mathbb{A}^{T}y$$
- Métrica de Erro (Norma $L_2$): Avaliação global do ajuste contra dados originais:
  $$e=\sqrt{\int_{t_{i}}^{t_{f}}[p(t)-\mathscr{P}(t)]^{2}dt}$$

4. CÁLCULO DE SENSIBILIDADES (Diferenciação Numérica)
- Intuição: Quantificar como as saídas do sistema ($\mathscr{P}$, $\mathfrak{q}_{inlet}$, Volume) variam com pequenas alterações nos parâmetros de projeto ($H$, $T_C$).
- Diferenças Finitas: Aproximação ex-post. A diferença centrada possui erro de truncamento $O(\epsilon^2)$:
  $$\frac{\partial \mathscr{P}}{\partial \Pi_{k}} \approx \frac{\mathscr{P}(\dots, \Pi_{k} + \epsilon, \dots) - \mathscr{P}(\dots, \Pi_{k} - \epsilon, \dots)}{2\epsilon}$$
- Método Direto Contínuo: Mais eficiente. Resolve as sensibilidades das variáveis de estado ($s_{p}^{n+1} = dp^{n+1}/dH$) acopladas ao sistema principal, permitindo a integração direta:
  $$\frac{d\mathscr{P}}{dH}=\int_{0}^{T}\left[ 2s_{p}^{T}(t)\mathbb{A}(H)p(t)+p^{T}(t)\frac{\partial\mathbb{A}(H)}{\partial H}p(t) \right]dt$$

5. RESOLUÇÃO DE EQUAÇÕES NÃO-LINEARES
- Intuição: Busca de raízes para problemas de otimização de projeto (ex: encontrar $H$ para a qual $\mathscr{P}(H) = 7.5$).
- Método de Newton-Raphson: Linearização local usando o operador derivada:
  $$x^{(k+1)}=x^{(k)}-\frac{F(x^{(k)})}{F'(x^{(k)})}$$

[ESTRUTURA ALGORÍTMICA]

[RISCOS E BOAS PRÁTICAS]
- Complexidade NP-Hard: Uma rede de 100 canais possui espaço amostral de 2^100. Jamais tentar busca exaustiva (loops iterativos sobre todas as combinações). 
- A convergência do estimador de Monte Carlo é lenta (proporcional a N^(-1/2)). Espera-se N=2000 realizações para o caso dinâmico. Otimizar a montagem das matrizes dentro do loop é crítico.

2. APRENDIZADO DE MODELOS (Interpolação e Regressão)
-----------------------------------------------------------------------------
[ESTRUTURA ALGORÍTMICA]
- Interpolação Global:
  * Via Vandermonde: `V = np.vander(x, N, increasing=True)` seguido de `c = np.linalg.solve(V, y)`.
  * Via Ajuste Nativo: `c = np.polyfit(x, y, grau)`. 
  * ATENÇÃO: `polyfit` retorna coeficientes em ordem DECRESCENTE de potência. Avaliar com `np.polyval(c, xeval)`.
- Interpolação Local (Splines): `from scipy.interpolate import interp1d`. Usar `kind='linear'` ou `kind='cubic'`.
- Geração de Ruído: Inserir perturbação no sinal de pressão via `p_inlet(t) = (5000 / p_atm) * [1 + (-0.15 + 0.3 * np.random.rand())]`.

[RISCOS E BOAS PRÁTICAS]
- Fenômeno de Runge (Bug Crítico): A interpolação polinomial global sobre malhas equiespaçadas gerará oscilações espúrias severas nas bordas do domínio. A solução idiomática e exigida para contornar isso é o uso de Splines (interpolação local).
- Overfitting/Underfitting: Ao utilizar Mínimos Quadrados via `polyfit`, atentar-se à variação do grau do polinômio (m de 3 a 15) contra a quantidade de dados.

3. CÁLCULO DE SENSIBILIDADES E DIFERENCIAÇÃO NUMÉRICA
-----------------------------------------------------------------------------
[ESTRUTURA ALGORÍTMICA E OTIMIZAÇÃO OBRIGATÓRIA]
- Diferenças Finitas: O passo de perturbação ótimo para dupla precisão (float64) deve ser epsilon_mach^(1/2) ~= 1e-8.
- Método Direto Contínuo (Gargalo de Desempenho): Executar a simulação duas vezes (forward differences) multiplicará o custo computacional.
  * Otimização Limpa (Clean Code): A matriz global acoplada `G` é INVARIANTE temporalmente e frente aos sistemas de estado e sensibilidade.
  * PRÁTICA EXIGIDA: Realizar a fatoração LU/Cholesky FORA do loop temporal:
    `SolveG = scipy.sparse.linalg.factorized(G)`
  * Dentro do loop, usar o operador pré-fatorado para atualizar os vetores de estado e as sensibilidades por substituição direta (muito mais rápido):
    `Ynew = SolveG(Yold)`
    `Snew = SolveG(Sold)`

[RISCOS E BOAS PRÁTICAS]
- Instabilidade Numérica: Diferenças finitas puras são extremamente sensíveis à amplificação de ruído estocástico no termo da pressão de entrada. O método contínuo via equações sensíveis acopladas (Equação 6.17) provê estabilidade superior.
